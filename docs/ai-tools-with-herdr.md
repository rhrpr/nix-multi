# AI tools with Herdr

Herdr is the terminal runtime for the native Claude, Codex, Gemini, Copilot and Hermes
CLIs. The previous examples in this file referenced obsolete or overlapping orchestration
commands.

Use the maintained guide:

- [Durable multi-agent development workflow](AI-AGENT-WORKFLOW.md)
- [Hermes and LM Studio setup](hermes-m4-24gb-end-to-end-setup.md)
