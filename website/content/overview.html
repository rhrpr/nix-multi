What this project is

A modular configuration repository for macOS and NixOS, with Home Manager, development shells, and optional VM and host tooling. It is a foundation to inspect and adapt, rather than a universal installer.

What to know first

You should be comfortable with Git, a terminal, and editing configuration files. NixOS users also need to understand their machine's disks, boot mode, and hardware configuration. Begin with the Nix learning resources if these concepts are new.

Read alongside the source

These guides describe the configuration in this checkout. The repository holds the implementation and detailed host-specific notes. Check the exact revision you use before following a command.
